# Blog content

Each published article is an `.mdx` file in this folder. Frontmatter fields:

```yaml
title: "..."
description: "..."   # used for SEO meta + OpenGraph
date: "YYYY-MM-DD"
excerpt: "..."       # short teaser for cards
tags: ["Tag"]
author: "Kinetic Physiotherapy"
draft: true          # set to false to publish
```

Drafts (`draft: true`) show in local dev but are hidden in production.
Set `draft: false` after the owner reviews the copy for accuracy.
